# Hi 👋🏻, I'm Kariebi Victor.

I work across application security, offensive security, and secure systems engineering. My work includes assessing web applications and APIs, reviewing code, improving security in development pipelines, and helping other security practitioners develop their skills.

I'm interested in how systems fail, how to test them responsibly, and how to build them better. Lately, I've been exploring AI security and building small, practical tools to learn by doing.

## Selected projects

| Project | What it does | Stack |
| --- | --- | --- |
| **[AgentSec](https://github.com/Kariebi-Victor/agentsec)** | A local LLM-powered security testing prototype that runs predefined authorization checks against a deliberately vulnerable API and produces JSON and HTML reports. | Python · Ollama · Qwen3 · FastAPI |
| **[Secure CI/CD Pipeline](https://github.com/Kariebi-Victor/secure-cicd-pipeline)** | A demonstration pipeline integrating secret scanning, static analysis, vulnerability scanning, and baseline dynamic testing. | GitHub Actions · Gitleaks · Semgrep · Trivy · OWASP ZAP |

> These are learning and engineering projects. AgentSec is a constrained proof of concept, not a general-purpose autonomous penetration testing tool.
